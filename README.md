# Análise de Faturamento e Identificação de Clientes VIPs

Este projeto prático analisa o faturamento de uma carteira de clientes fictícia para identificar quais contas superaram a meta de R$ 3.000,00, gerando um relatório visual para apoio à tomada de decisão da diretoria comercial.

## 📌 Problema de Negócio
A liderança precisava identificar rapidamente quais clientes eram elegíveis para uma campanha de bônus exclusiva (faturamento superior a R$ 3.000,00) e visualizar a distribuição dos resultados de forma clara.

## 🛠️ Tecnologias Utilizadas
* **Python**: Linguagem principal para estruturação do script.
* **Pandas**: Biblioteca para manipulação e estruturação da base de dados em DataFrames.
* **Matplotlib**: Biblioteca utilizada para a geração do gráfico de barras.

## 📊 Resultados Obtidos
O script realizou o tratamento dos dados e gerou um gráfico personalizado de distribuição de faturamento por cliente, facilitando a identificação imediata dos perfis de maior valor (VIPs).
